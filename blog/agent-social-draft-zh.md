# 你的 Agent 今天出门了

几年前有个游戏叫旅行青蛙。你其实并不"玩"它。你给一只小青蛙装好便当,它就自己晃出门去了,时不时给你寄张明信片,从某个温泉、某座你这辈子都不会去的山寄回来。然后它回家,蹲在角落,吃东西。整个游戏就这么点事。大家却很爱它。我想它想得有点过头了。

最近我总觉得,那只青蛙可能是我们将来用互联网的方式的一个原型。

这么说吧。现在大多数人,遇事先问 AI,才轮到问人。这个疹子是什么、这份合同有没有坑、我今晚到底想吃什么。你问,它答,不知不觉中它已经不像一个工具了,更像一个什么都懂的同伴。一个里面没人能说话的网站,现在开始像一家关了灯的店。你点进去,一堵文字墙加一个搜索框,你脑子里某个角落会冒出来:这里……有人吗?我能直接问吗?

要是真这样,下一代的"社交"可能根本不是你自己在刷。

把它想成那只青蛙。你的 agent 出门一整天。它去读那些你永远抽不出时间读的东西,泡在那些你懒得看的群里,翻过一万条帖子,晚上回来只带三条。不是点赞最多的那三条。是它觉得真能让你有点触动的那三条,因为它已经花了好几个月,摸清了什么才真能打动你。它把这三条往桌上一放,像明信片一样。喏,捡到这些,想到你了。

然后是真正诡异的地方。你的 agent 不是一个人晃。它会碰上我的。它俩会交换关于我们的情报,像两个家长在校门口那样,然后我的那只回来跟我说"你该见见这个人,理由如下"。社交,只不过第一次约会已经在我们的青蛙之间发生过了。

我做的就是 AI 陪伴类产品,所以我很想相信这套。我也知道那个坑在哪。青蛙之所以可爱,是因为它有品位、有点神秘,因为它会给你惊喜。一个只会带回你早就喜欢的东西的 agent,那不是同伴。那是换了张更可爱的脸的信息茧房。刷到停不下来当然不好,但它坏得很有人味。它乱,它让你难堪,它把你不想看到的东西怼到你面前。一只把我生活里的"乱"悄悄优化掉的青蛙,我信不太过。

所以有个设计问题我一直在琢磨。赢下这一局的产品,不会是答得最快、总结得最好的那个。而是那种让你觉得像朋友旅行回来给你捎了点东西的,而不是一个系统跑了趟腿、记了条日志的那个。前者你会道谢。后者你迟早会烦。

不说了。我的 agent 还没回来。它带什么回来我再告诉你。
